# 动态规划

动态规划（Dynamic Programming，DP）是一种通过把原问题分解为子问题，再从子问题的解得到原问题的解的方法。动态规划常常用于求解最优化问题，也就是求解一个给定问题的最优解。

## 2. 自底向上

自底向上法（Bottom-up）是指从原问题开始，一步步推导出其子问题的最优解，直到得到原问题的最优解。


## 3. 解题步骤

动态规划的解题步骤一般分为以下几步：

1. 定义子问题
2. 递归定义子问题
3. 计算子问题的最优解
4. 构造原问题的最优解

## 4. 技巧

1. 穷举所有解法
2. 寻找 base case
3. 画状态转移图
4. 利用备忘录或滚送数组优化

c. 确定【目标】，即 dp 函数/数组的定义，一般来说，函数的参数就是代表【状态】的变量

动态规划适用于很多问题，如：

2. 最大子数组问题
3. 背包问题
4. 股票交易问题
5. 旅行推销员问题
6. 数学问题
7. 机器学习问题
8. 图论问题
